Запуск одиночных исходящих звонков

POST: https://twin24.ai/cis/api/v1/telephony/autoCallCandidate/single

Тип авторизации: BEARER

Описание

Метод позволяет создать задание на обзвон, добавить в него кандидата и запустить задание для звонка добавленному кандидату.

Перед запуском метода необходимо создать шаблон задания на обзвон и установить настройку использования этого шаблона по умолчанию. Подробнее читайте в статье Управление шаблонами.

При использовании метода создается одно задание на обзвон в сутки под каждого участвующего бота. Повторный вызов метода добавляет новых кандидатов в уже созданное задание.

Все настройки создаваемого задания, кроме сценария бота, берутся из шаблона по умолчанию. Если в шаблоне изменились настройки, при следующем запросе создается новое задание.

Сценарий бота, который будет использоваться в звонках, указывается в теле запроса в поле botSettingsId.

Примеры запроса

curl --request POST \
     --url https://twin24.ai/cis/api/v1/telephony/autoCallCandidate/single \
     --header 'accept: application/json' \
     --header 'authorization: Bearer ТОКЕН' \
     --header 'content-type: application/json' \
     --data '
{
  "callbackData": {
    "test": "123"
  },
  "phone": [
    "79991234567"
  ],
  "botSettingsId": "2656622a-57b2-478f-acf9-6167120d18bf",
  "variables": {
    "Имя": "Николай",
    "Возраст": "28"
  },
  "timezone": 16800
}
'
